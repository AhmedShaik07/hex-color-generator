# 🎨 Hex Color Generator

This is a simple and interactive Hex Color Generator web application. With a single button click, it generates a random hex color code, displays the color in a box, and shows the corresponding hex code.

## 🚀 Features

- Generates random hex color codes (`#RRGGBB`)
- Displays the generated color in a preview box
- Shows the exact hex code as text
- Simple UI with a single click interaction

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
